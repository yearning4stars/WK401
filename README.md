# คลังความรู้ ม.ปลาย

คลังเนื้อหาสำหรับเรียนรายเรื่อง เริ่มจาก ม.4 สายวิทย์-คณิต แล้วขยายไปชั้นสูงขึ้น แต่ละเรื่องมีสรุปเนื้อหา ตัวอย่าง แบบฝึกหัดพร้อมเฉลย และ **ดัชนีลิงก์ไปยังข้อสอบจริง** ที่เกี่ยวข้อง

เป็นเว็บ static ล้วน (HTML + CSS + JavaScript) โฮสต์ฟรีบน GitHub Pages ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่เก็บข้อมูลผู้เรียน

> **สถานะ** เริ่มต้น มีฟิสิกส์ ม.4 ตัวอย่าง 3 เรื่อง เนื้อหาทั้งหมดเป็น **ฉบับร่าง** (`status: draft`) ที่ร่างด้วย AI และยังไม่มีครูตรวจทาน ควรให้ครูหรือผู้เชี่ยวชาญตรวจก่อนเผยแพร่จริง แล้วเปลี่ยนเป็น `status: reviewed` ทีละเรื่อง
> ส่วนข้อสอบจริง **ยังไม่มีลิงก์ใดอยู่ในดัชนี** (`exams: []`) เพราะต้องคัดลิงก์จากต้นทางที่ตรวจแล้วว่าเปิดเผยแพร่จริง ดู [แนวทางหาแหล่งข้อสอบ](#แหล่งข้อสอบที่ควรไล่หา)

## หลักการ

1. **เนื้อหาต้นฉบับ** เขียนเองหรือได้รับอนุญาต เผยแพร่ภายใต้ [CC BY-SA 4.0](CONTENT_LICENSE.md)
2. **ข้อสอบจริงเก็บเป็นลิงก์เท่านั้น** ชี้ไปยังหน้าต้นทางที่เจ้าของข้อสอบเผยแพร่เอง ไม่เก็บสำเนาไฟล์หรือพิมพ์โจทย์ซ้ำ เพราะข้อสอบส่วนใหญ่มีลิขสิทธิ์ สคริปต์ตรวจจะไม่ยอมให้มีไฟล์ PDF/Word ใน `content/`
3. **ไม่เก็บข้อมูลผู้ใช้** ความคืบหน้า ("เรียนแล้ว") อยู่ใน `localStorage` ของเบราว์เซอร์เท่านั้น ไม่ใช้ฟอนต์หรือสคริปต์วิเคราะห์ข้อมูลจากบริการภายนอก (ยกเว้น KaTeX, marked, DOMPurify จาก CDN ดูหัวข้อแผนต่อ)
4. **เพิ่มเนื้อหาด้วยไฟล์ Markdown** ไม่ต้องเขียนโค้ด และมีสคริปต์ช่วยตรวจรูปแบบให้ก่อนรวม PR

## โครงสร้างโปรเจกต์

```
content/
  taxonomy.json              รายการระดับชั้นและวิชา
  <ระดับ>/<วิชา>/<เรื่อง>.md   เนื้อหาแต่ละเรื่อง (m4/physics/newtons-laws.md)
templates/topic.md           แม่แบบสำหรับเรื่องใหม่
scripts/                     ตัวตรวจเนื้อหาและตัวสร้าง content/index.json
assets/                      หน้าเว็บ (app.js, style.css, config.json)
tests/                       ชุดทดสอบของสคริปต์ตรวจ
.github/                     workflow ตรวจและ deploy, แม่แบบ PR และ issue
index.html                   หน้าเว็บ
```

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป และ python3 (ใช้เปิดเซิร์ฟเวอร์ชั่วคราว)

```bash
npm run dev        # ตรวจเนื้อหา สร้างดัชนี แล้วเปิด http://localhost:8080
npm run check      # ตรวจเนื้อหาอย่างเดียว
npm test           # รันชุดทดสอบ
```

ไม่ต้อง `npm install` เพราะไม่มี dependency ฝั่งนักพัฒนา เปิดหน้าเว็บผ่านเซิร์ฟเวอร์เท่านั้น (เปิดไฟล์ `index.html` ตรงๆ จะโหลดข้อมูลไม่ได้)

## เพิ่มเรื่องใหม่

```bash
cp templates/topic.md content/m4/physics/work-energy.md
# แก้ frontmatter และเนื้อหา แล้วตรวจ
npm run check
```

รายละเอียดการเขียน การใส่ลิงก์ข้อสอบ และเกณฑ์ตรวจทาน อยู่ใน [CONTRIBUTING.md](CONTRIBUTING.md)

เพิ่มระดับชั้นหรือวิชาใหม่ได้ที่ `content/taxonomy.json` (เช่น เพิ่ม `university` เป็นระดับ แล้วสร้างโฟลเดอร์ตามชื่อ id)

## เผยแพร่บน GitHub Pages

1. สร้าง repository บน GitHub แล้ว push โค้ดขึ้น branch `main`
2. ไปที่ **Settings → Pages** เลือก Source เป็น **GitHub Actions**
3. workflow `.github/workflows/pages.yml` จะทดสอบ สร้างดัชนี และ deploy ให้อัตโนมัติทุกครั้งที่ push
4. ใส่ลิงก์ repository ใน `assets/config.json` (ช่อง `repoUrl`) เพื่อให้หน้าเว็บมีลิงก์ GitHub
5. ใส่ชื่อเจ้าของลิขสิทธิ์ในไฟล์ `LICENSE`

## แหล่งข้อสอบที่ควรไล่หา

ประเภทแหล่งที่น่าจะมีข้อสอบเปิดเผยแพร่ และควรตรวจเงื่อนไขการเผยแพร่ของแต่ละที่ก่อนใส่ลิงก์

- ข้อสอบ A-Level / TCAS ของหน่วยงานที่จัดสอบ
- ข้อสอบคัดเลือก สอวน. ที่ศูนย์ต่างๆ เผยแพร่
- ข้อสอบ O-NET ของ สทศ.
- ข้อสอบเข้า ม.4 หรือข้อสอบวัดผลที่โรงเรียนและมหาวิทยาลัยเผยแพร่เอง

ใส่เป็นลิงก์ไปหน้าต้นทาง ระบุปีเป็น พ.ศ. และข้อที่เกี่ยวข้องกับเรื่องนั้นให้ตรงที่สุด หน้าเว็บบางแห่งอาจย้ายหรือปิด จึงควรตรวจลิงก์เป็นระยะ
